# Playbook: housekeeping review at the end of a coding task

Follow this when a coding task is about to be closed, before the housekeeping of CONVENTIONS.md.

1. Sanity: does the change do what Leon asked, nothing more? Any file touched that was not needed?
2. Docs of the project: are CLAUDE.md, STATE.md, ROADMAP.md and LOG.md (where they exist) updated by Claude Code? If not, send a follow-up task.
3. Leftovers: placeholder text, test data, commented-out code, secrets, long dashes in texts.
4. Design: anything visual follows lacande/foundations/LACANDE-DESIGN.md.
5. Going live: website changes wait for Leon's "put it live"; LacandERP, NFC Candle app and Talented CRM wait on a branch for Leon's OK.
6. Write the result in the box's log.md in one line, and in memory.md if a convention or decision changed.

Leon adds to this list over time: "Hermes, add to the coding playbook: ...".
