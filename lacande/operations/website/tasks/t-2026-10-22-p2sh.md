# Patch the web server against PHP2Shell

Leon asked for a three phase patch (diagnose, patch after OK, verify) of PHP on the OVH VPS for CVE-2026-109618 and CVE-2026-109619.

## Notes, round 1 (2026-10-22)
- Hermes's container reaches only the internet and the public site, not the server's shell. No server access was attempted beyond public HTTP.
- From the infrastructure doc (repo, v4): Ubuntu 26.04, CloudPanel, PHP 8.3.31 via PHP-FPM, nginx on 443 > Varnish > nginx on 8080. Recorded, not freshly measured.
- Ubuntu 26.04 ships PHP 8.5 only ("php8.3: not in release" on Ubuntu's CVE page). So PHP 8.3 there comes from a third-party source (likely CloudPanel's repo or ondrej/sury). Ubuntu's notice USN-8948-1/-2 does not cover it.
- Ubuntu fixed php8.5 for 26.04 in 8.5.4-0ubuntu1.5 (relevant only if php8.5 is installed too).
- ondrej's Launchpad lists 8.3.36 for noble and jammy. Not confirmed for 26.04 (resolute).
- Public check: site answers (302 to /en, 200; /panel 302). nginx hides the PHP version.
- Read-only script ready: /workspace/files/php2shell-phase1-diagnose.sh
